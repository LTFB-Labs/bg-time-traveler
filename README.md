# Пътешествие във времето

Детска игра по история на България от 600 г. до днес. Дърпаш слайдъра най-долу и картата на Балканите показва как се менят границите, а отгоре излизат важните събития, личности и сгради с кратък текст и снимка.

## Как да я пуснеш

```bash
python3 -m http.server 8765
```

След това отвори http://127.0.0.1:8765/.

Урок се отваря и директно по адреса му: `#lesson/<номер на урока>/<част>`, например http://127.0.0.1:8765/#lesson/5-odrisko-tsarstvo/0. Частта е по избор: 0 е началото (прегледът на урока), а последната част е обобщението. Без номер на част урокът се отваря там, където детето е спряло.

## Как се добавя съдържание

Преди първото пускане: `cd tools && npm install`. Всичко се пише във `content/`. Ако нещо не е наред, сглобяването спира със съобщение, което казва в кой файл е грешката.

### Картичка

Файл `content/cards/<id>.md`. Името на файла трябва да е същото като `id`.

```
---
id: teres
kind: person
title: Терес I
aliases: [Терес, Терес Първи]
---
Първи абзац.

Втори абзац.
```

- Задължителни: `id`, `kind`, `title`.
- `kind` е едно от: `person`, `place`, `object`, `people`, `idea`, `event`, `state`.
- Два абзаца, всеки от 50 до 90 думи. Картичка от вид `event` може да има един абзац и без ограничение за думите.
- По желание: `dates`, `at: [дължина, ширина]` (маркер на картата; дължина от 12 до 42, ширина от 34 до 49.5), `years: [от, до]`, `photo` (ключ от `photos.json`).
- `aliases` са формите, под които картичката се споменава в уроците. В урока ги пишеш получер, например `**Терес**`, точно както са в списъка. Заглавието е псевдоним автоматично.

### Урок

Файл `content/lessons/<клас>/<име>.md`. Най-добре е да копираш `content/lessons/5/odrisko-tsarstvo.md` и да го промениш.

След това добави урока в `content/lessons/5/index.json` с `id`, `file` и `state: ready`:

```json
{ "id": "5-odrisko-tsarstvo", "file": "odrisko-tsarstvo.md", "state": "ready" }
```

Урок, който го няма в този списък, спира сглобяването.

- В началото: `id`, `grade`, `number`, `title`, `map`, `span: [от, до]`, `eras`.
- Първо е част `summary` (`<!-- part: summary -->`, в нея пишеш `year: span`), накрая е част `check`. Между тях има от 6 до 8 части на историята.
- Всяка част на историята има 3 абзаца по 60 до 90 думи (строго: 3 или 4 абзаца, 40 до 110 думи, общо най-много 1800 думи за историята).
- Във всяка част има точно един цитат, който започва с `> Знаеш ли, че…`.
- Всяка част има блок с ключове веднага след заглавието. Нужен е `year` или `label`. Позволени са само: `year`, `approx`, `label`, `box`, `borders`, `ghost`, `marks`, `path`, `photo`, `words`, `next`, `predict`. Частта `summary` има още `lead`, `goals`, `names`, а `check` има само `questions`.
- Въпросите в `check` са от 5 до 7. Видове: `tap`, `order`, `pick-border`, `choose`, `match`.
- Всички идентификатори (граници, картички, снимки) трябва да съществуват.

### Граница

Един GeoJSON файл в `content/borders/`. Как се рисува и кои свойства са задължителни е описано в [content/borders/README.md](content/borders/README.md). Името на файла е идентификаторът, който уроците ползват.

### Снимка

1. Намери файла в Wikimedia Commons и копирай името му.
2. Добави в `content/photos.json`:

```json
"moya-snimka": {
  "src": "Име_на_файла_от_Commons.jpg"
}
```

3. Пусни `npm run photos` в `tools/`. Снимката се изтегля в `photos/`, а авторът и лицензът се записват сами.
4. После пусни `npm run build`, за да се покаже снимката.

Приемат се само свободни лицензи: обществено достояние, CC0 и CC BY (без NC и ND). Другите се отхвърлят със съобщение. Списъкът с автори в `CREDITS.md` се обновява сам.

### Кога коя команда

Всички се пускат от папката `tools/`.

- `npm run photos` след добавяне на снимки.
- `npm run geo` след промяна на граници.
- `npm run build` след всяка промяна на съдържанието: текст, снимки и граници (след `npm run photos` или `npm run geo` също).
- `npm test` проверява инструментите.

`content.js`, `geo.js` и `CREDITS.md` се генерират, но се записват в git заедно с промените.

## Файлове

- `index.html` е страницата и стиловете на свободната линия на времето. Кодът е в `js/`: свободната линия, урокът, картата, проверката и обобщението, по един файл на задача.
- `css/lesson.css` са стиловете на урока. `content/figures/` са фигурките, които се движат по стрелките на картата.
- `content/` е мястото на данните: `cards/` (събитията като Markdown картички), `photos.json`, `maps/balkans.json` (епохи, владетели, градове, камера). `content.js` се генерира с `cd tools && npm run build`.
- `geo.js` е генериран. Пуска се с `cd tools && npm install && npm run ne && npm run geo` (`npm run ne` тегли Natural Earth файловете). Историческите граници са ръчно начертани в `tools/defs.mjs`. Тестовете се пускат с `npm test` в `tools/`.
- `photos/` са снимките от Wikimedia Commons. Авторите и лицензите са в [CREDITS.md](CREDITS.md).

Картата е направена с данни от [Natural Earth](https://www.naturalearthdata.com/) (public domain). Историческите граници са приблизителни и са рисувани на ръка за деца.
