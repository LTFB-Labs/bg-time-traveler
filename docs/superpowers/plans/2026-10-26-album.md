# The album with opened cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An album page that shows every card the child has opened, grouped by lesson and by the free map, with counts of what is left; free-map events count as opened when the year stops on them.

**Architecture:** Lesson cards are already counted: the card pop-over (`js/cards.js`) calls `markCardOpened` for a bold term, a marker and a free-map search result. The free map gains one place that marks the event whose card the panel shows, called when the year stops. A new address `#free/<id>` opens the free map on one event, so the album can show an event on the map. A new module `js/album.js` holds a pure function that groups the opened card ids, tested in node, and draws the album at `#album`, reached from the lesson list.

**Tech Stack:** Plain ES modules in the browser, no bundler; Node's built-in test runner (`npm --prefix tools test`).

**Spec:** `docs/superpowers/specs/2026-10-25-free-map-search-lessons-album-design.md`, section 7 (with sections 2 and 8 for goals and constraints). The Герои part of section 7 comes with the hidden characters (Part 4); this plan builds the Картички part only.

**Before you start:** branch off main (`git checkout -b album`).

## Global Constraints

- A static site: plain ES modules, no bundler, no new dependencies. Code holds no history text. Interface text is Bulgarian.
- No browser alert, confirm or prompt dialogs.
- A still screen runs no animation at all. Nothing in this plan animates; the wheel's stop check is a one-shot timer.
- Any hash change reloads the page (`js/app.js`); new addresses follow that rule.
- A free-map event counts as opened only when the year stops on it with its card in the panel: at the end of a year move (a search pick, a marker or dot click, Next and Prev, each Play step, the arrow keys), at the end of a drag, when a wheel scrub pauses for 300 ms, and when the start screen closes on the first event. The knob passing over events during a drag or a move counts nothing (Martin's decision).
- Copy, exactly: list button `Албум`; album heading `Албум`; section heading `Картички`; lesson group `Урок N · <title>` with `N от M картички от този урок`; free-map group `Свободната карта` with `N от M събития от картата`; empty lesson group `Отвори картичка в урока и тя ще дойде тук.`; empty free-map group `Спри годината на събитие на картата и то ще дойде тук.`; card button `Покажи на картата`; the album's way back `Към началото`.
- New code: 4-space indent, single quotes, semicolons, trailing commas in multiline literals. In `js/free.js` and `index.html`, untouched lines keep their older style.
- Browser checks run against the repo root served without caching (the no-cache server on port 8778 if it runs, else `python3 -m http.server`), and the test browser is closed afterwards.

## Review Focus

1. One drag of the knob from 600 to today adds exactly one event, the one it stops on. (Task 1, browser check.)
2. A year move cut short by a click, a new search pick or a drag adds nothing for the move that was cut. (Task 1, browser check.)
3. `#free/<id>` with an id that is not an event opens the free map as usual, start screen included. (Task 2, browser check.)
4. An opened id that belongs to no group (a card renamed or removed since, or a card no lesson uses) changes no count. (Task 3, test `ignoresOpenedCardsOutsideTheGroups`.)
5. An album with nothing opened shows every group with `0 от M` and its hint, not an empty page. (Task 3, test `emptyAlbumKeepsEveryGroup` and browser check.)

### Task 3: The album page

**Files:**
- Create: `js/album.js`
- Modify: `js/app.js` (route), `index.html` (album markup, list door), `css/lesson.css` (album CSS, the pop-over's place in the album), `README.md`
- Test: `tools/test/web-album.test.mjs`

**Interfaces:**
- Consumes: `loadProgress().cards` (Task 1 fills it with events too); `#free/<id>` (Task 2); `createCards` from `js/cards.js`; the search index's card entries, which carry `lesson` and `part` (as `lessonLink` in `js/free.js` uses them); `CONTENT.lessons`, `EVENTS`, `CONTENT.cards`, `CONTENT.photos`.
- Produces: `albumGroups({ lessons, events, opened })` returns `[{ name, ids, count, empty }]`: one group per lesson in the order given, then one for the free map. `ids` are the opened cards of the group in the group's order; `count` is the count line; `empty` is the group's hint. `startAlbum()` draws the page.

A lesson's cards are the ids in its parts' `meta.marks` and in the `data-card="…"` attributes of each part's `html` and `factHtml`, in order of first appearance, each once. The free map's cards are the events, in the order given (`EVENTS`, sorted by year).

The page, at `#album`:
- The same full-window paper sheet as the lesson list (share its rules): `Към началото`, the heading `Албум`, then the section heading `Картички`.
- Each group: its name, its count line, then a grid of tiles, one per opened card: a small picture (the card's photo, lazy-loaded, or its kind's icon) and the title. A group with no opened card shows its hint instead of a grid.
- A tile is a button. It opens the card in the pop-over used on the free map (`#freePop` and `createCards`), placed above the album. The card's footer is `Покажи на картата`: for an event, a link to `#free/<id>`; for a lesson card, a link to the part where it first appears (`#lesson/<lesson>/<part>`); no button for a card with neither.
- The lesson list gets an `Албум` link to `#album` in its top row, across from `Към началото`.
- `body.album` hides the free map's furniture, as `body.lessons` does.

- [ ] **Step 1: Write the failing tests** in `tools/test/web-album.test.mjs`:

```js
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { albumGroups } from '../../js/album.js';

const part = (marks, html = '', factHtml = '') => ({ meta: { marks }, html, factHtml });
const LESSON = {
    id: '5-test',
    number: 26,
    title: 'Древна Тракия',
    parts: [part(['teres'], '<b class="term" data-card="sitalces">Ситалк</b>'), part(['teres', 'kabyle'], '', '<b data-card="orpheus">Орфей</b>')],
};
const EVENTS = [{ id: 'asparuh' }, { id: 'krum' }, { id: 'simeon' }];
const groups = (opened) => albumGroups({ lessons: [LESSON], events: EVENTS, opened });

test('groupsLessonCardsInLessonOrder', () => {
    assert.deepEqual(groups(['kabyle', 'teres'])[0], {
        name: 'Урок 26 · Древна Тракия',
        ids: ['teres', 'kabyle'],
        count: '2 от 4 картички от този урок',
        empty: 'Отвори картичка в урока и тя ще дойде тук.',
    });
});

test('countsFreeMapEventsInTheirOrder', () => {
    assert.deepEqual(groups(['simeon', 'asparuh'])[1], {
        name: 'Свободната карта',
        ids: ['asparuh', 'simeon'],
        count: '2 от 3 събития от картата',
        empty: 'Спри годината на събитие на картата и то ще дойде тук.',
    });
});

test('ignoresOpenedCardsOutsideTheGroups', () => {
    const [lesson, events] = groups(['athens', 'old-id', 'orpheus']);
    assert.deepEqual(lesson.ids, ['orpheus']);
    assert.deepEqual(events.ids, []);
});

test('emptyAlbumKeepsEveryGroup', () => {
    assert.deepEqual(groups([]).map((g) => g.count), ['0 от 4 картички от този урок', '0 от 3 събития от картата']);
});
```
