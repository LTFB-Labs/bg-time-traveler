# Граници за уроците

Всеки файл тук е една граница: GeoJSON `Feature` с `Polygon` или `MultiPolygon` в дължина и ширина. Името на файла (без `.geojson`) е идентификаторът, който уроците използват.

## Как да нарисуваш граница

1. Отвори geojson.io и нарисувай многоъгълника върху картата.
2. Копирай GeoJSON от дясния панел. Нужен е само един `Feature`, не `FeatureCollection`.
3. Добави свойствата по-долу и запази файла тук като `име-на-границата.geojson`.

## Задължителни свойства

- `name`: името, както се вижда на картата, на български.
- `kind`: `state` за държава или `tribes` за племена. Ъглите на `tribes` се изглаждат по-силно, както при племената в `tools/defs.mjs`.
- `colour`: цвят като `#c8402f`.

Файл без някое от тях спира сглобяването и съобщението носи името на файла.

## Как да сглобиш картата отново

    cd tools && npm run geo

Командата записва границите в `geo.js` под `GEO.borders`.
